# Plantillas de mensajes de WhatsApp

Reemplaza lo que está entre `{llaves}`. Los mensajes fuera de la ventana de 24 h deben registrarse como **plantillas aprobadas por Meta**.

## Flujo A · Bienvenida

```
¡Hola {nombre}! 👋 Gracias por escribir a Fonazo.
¿En qué te ayudamos? Responde con un número:
1️⃣ Celulares
2️⃣ Accesorios
3️⃣ Servicio técnico
4️⃣ Garantía o reclamo
```

## Flujo A · Fuera de horario

```
¡Hola {nombre}! Ahora estamos fuera de horario. Te respondemos mañana desde las {hora_apertura}.
Si nos cuentas qué modelo buscas, te tenemos la información lista a primera hora. 📱
```

## Flujo B · Seguimiento 1 (24 h)

```
Hola {nombre}, ¿pudiste revisar la información del {modelo}? Si tienes alguna duda sobre precio, colores o forma de pago, aquí estoy para ayudarte.
```

## Flujo B · Seguimiento 2 (72 h)

```
{nombre}, te separamos el precio del {modelo} hasta el {fecha}. Si lo llevas esta semana, te regalamos la mica de vidrio templado. 🎁 ¿Te lo reservo?
```

## Flujo C · Agradecimiento + encuesta (día 1)

```
¡Gracias por tu compra, {nombre}! Tu {producto} tiene garantía de {meses} meses; guarda tu comprobante.
¿Cómo calificarías tu atención del 1 al 5?
```

## Flujo C · Accesorios (día 7)

```
Hola {nombre}, ¿qué tal tu {modelo}? Tenemos cases, micas y cargadores rápidos compatibles. Responde "VER" y te enviamos fotos y precios.
Responde SALIR si no deseas recibir ofertas.
```

## Servicio técnico · Equipo listo

```
Hola {nombre}, tu equipo con código {codigo} ya está listo para recoger. 🔧✅
Horario: {horario}. Puedes ver el estado aquí: {link_rastreo}
```

## Ticket creado

```
Registramos tu caso con el código {ticket}. Lo está revisando {responsable} y te responderemos antes de {plazo}.
```
